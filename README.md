# Expressive Files 1.4

Проводник для Android с полноценной поддержкой архивов в дизайне **Material 3 Expressive**.

- Пакет: `com.klan3s.files`
- Готовый APK: `../ExpressiveFiles-v1.4.apk` (Android 8.0+, подписан debug-ключом)
- Исходники: Kotlin + Jetpack Compose, ~2 800 строк

---

## Возможности

### Хранилища
Стартовый экран показывает все накопители с индикатором занятого места:
- **Внутренняя память**
- **SD-карты** — через `StorageManager` и `getExternalFilesDirs`
- **USB-флешки (OTG)** — `StorageManager`, прямой скан `/storage/*`, `/mnt/media_rw/*`, `/mnt/usb*`; `UsbManager` помогает отличить флешку от SD
- **Корень системы `/`** — при включённом root

Если Android не даёт прямого доступа к накопителю (типично для USB-OTG), приложение предложит выдать его через системный диалог (**SAF / DocumentsContract**). Разрешение сохраняется, в SAF-режиме работают все операции: просмотр, создание папок, переименование, удаление, копирование/перемещение между любыми томами, открытие и распаковка архивов, создание архивов на флешке.

### Проводник
- Хлебные крошки, поиск в папке, сортировка (имя / размер / дата / тип), скрытые файлы
- Три вида: **список**, **компактный**, **сетка** (2–6 колонок), миниатюры изображений
- Выделение долгим нажатием → плавающая панель: сжать, копировать, переместить, переименовать, удалить
- Меню «+»: новая папка, открыть архив через системный пикер, вставить из буфера
- Открытие файлов во внешних приложениях, приём архивов из других приложений (intent-filter)

### Архивы
Архив открывается как обычная папка с навигацией по вложенным каталогам.

| Операция | Форматы |
|---|---|
| Чтение / распаковка | ZIP, JAR, APK, **7z** (в т.ч. с паролем), **RAR** (RAR4), TAR, TAR.GZ, TAR.BZ2, TAR.XZ, GZ, BZ2, XZ |
| Создание | **ZIP** (уровень 0–9), **7Z** (LZMA2 / LZMA / BZip2 / Deflate / без сжатия), **TAR**, **TAR.GZ**, **TAR.XZ**, **TAR.BZ2** (уровень сжатия) |

- Распаковка всего архива или только выбранных файлов/папок
- Для каждой записи показывается размер → сжатый размер и % экономии
- Защита от zip-slip (пути с `..` отбрасываются)

### Root-режим
- Запрос `su` (Magisk / KernelSU / SuperSU) по тумблеру в настройках или кнопке на главном экране
- Просмотр и запись в `/`, `/data`, `/system`, `/vendor`… (листинг через `ls -la`)
- Через root работают удаление, переименование, создание папок, копирование, открытие/распаковка/создание архивов в системных папках (через промежуточный кэш)
- После перезапуска приложения root-сессия восстанавливается автоматически; отключается только при явном отказе `su`

### Настройки
| Раздел | Опции |
|---|---|
| Тема | Системная / светлая / тёмная; 11 цветов + Dynamic Color (Android 12+); AMOLED-чёрный фон |
| Отображение | Вид (список / компактный / сетка), число колонок, стиль иконок (фигуры M3 / скруглённые / круги), миниатюры, подробности, папки сверху, скрытые файлы, сортировка |
| Архивы | Формат и степень сжатия по умолчанию |
| Root | Включение root, подтверждение удаления |

Цветовые схемы генерируются из seed-цвета целиком (primary / secondary / tertiary / surface). Цвет текста на любом элементе вычисляется по яркости фона: на светлом — чёрный, на тёмном — белый, в том числе для Dynamic Color.

## Структура проекта
```
app/src/main/java/com/klan3s/files/
├── MainActivity.kt
├── data/
│   ├── ArchiveService.kt   — чтение/запись всех форматов (commons-compress, xz, junrar)
│   ├── FileOps.kt          — операции с файлами, fallback на root
│   ├── RootShell.kt        — su: проверка, листинг, cp/mv/rm
│   ├── SafOps.kt           — доступ к томам через DocumentsContract
│   ├── Volumes.kt          — обнаружение внутренней памяти, SD, USB, root
│   ├── Settings.kt         — наблюдаемые настройки поверх SharedPreferences
│   └── Models.kt
└── ui/
    ├── App.kt              — проводник, просмотр архива, диалоги, панели
    ├── HomeScreen.kt       — экран хранилищ
    ├── SettingsScreen.kt
    ├── Components.kt       — строки/плитки файлов, иконки, миниатюры
    ├── MainViewModel.kt    — вся логика состояния
    └── theme/Theme.kt      — схема из seed-цвета, контраст текста
```

## Сборка
Открыть папку в Android Studio (Ladybug или новее), либо из консоли:
```
./gradlew assembleRelease   # или assembleDebug
```
Стек: Kotlin 2.1.20, AGP 8.9.3, Gradle 8.11.1, Compose BOM 2025.10.00,
material3 **1.4.0-alpha18** (стабильная 1.4.0 в репозитории не содержит Expressive-компонентов),
commons-compress 1.27.1, xz 1.10, junrar 7.5.5, documentfile 1.0.1.

Разрешения: `MANAGE_EXTERNAL_STORAGE` (все файлы), на Android ≤ 12 — `READ/WRITE_EXTERNAL_STORAGE`.

## Ограничения
- RAR5 не поддерживается (junrar читает только RAR4); создание RAR невозможно (закрытый формат)
- Шифрование при создании архивов не реализовано; чтение зашифрованных 7z — поддерживается
- APK подписан debug-ключом — для публикации нужна своя подпись
